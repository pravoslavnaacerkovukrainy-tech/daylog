# «Хаос Дня» — дизайн (редакция 2: нативный macOS + простой план дня)

Процесс: скилл `frontend-design:frontend-design` (plan → review against brief → build → critique).
Скилл писался для веба; здесь его метод применён к нативному SwiftUI: токены, макет, ревизия штампов, одна смелая деталь.

## Предмет, аудитория, задача
Личный дневник уже прожитого дня. Человек за Mac, иногда записывает задним числом то, что было вне компьютера.
Главное: быстро записать, потом спокойно перечитать день. План — маленький список «что хочу сделать сегодня»,
который при отметке превращается в запись дневника. Без метрик, серий, напоминаний и категорий.

## Токены
Цвет (светлая / тёмная тема):
| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| canvas | `textBackgroundColor` (#FFFFFF) | системный | лента дня — «лист» |
| pane | `windowBackgroundColor` | системный | панель плана, хром |
| ink | #263747 | `labelColor` | основной текст |
| quiet | #657586 | `secondaryLabelColor` | время в поиске, контекст, подписи |
| ink blue (accent) | #2F6690 | #86B6E0 | время, точки на оси, главное действие |
| rail | #DCE5EC | `separatorColor` | ось времени, контуры |

Шрифт: только системный SF. SF Pro для текста; время — SF Pro Rounded, полужирный, моноширинные цифры.
Шкала: заголовок дня 28/bold, подзаголовок title3, текст body (13), контекст callout, подписи caption.
Иконки — SF Symbols. Тёмная тема через семантические цвета.

## Макет
```
┌ toolbar: ‹ ›  Сегодня  [дата]                         [◧ План] ┐
│ 1 ноября            Поиск по всем дням…  │ План на день          │
│ сегодня, воскресенье                     │ [+ Добавить в план  ] │
│ ┌ Что сделано или произошло?         ┐   │ ○ Купить хлеб         │
│ │ □ Другое время  □ На чём…  [Записать]│ │ ○ Позвонить в сервис  │
│ └────────────────────────────────────┘   │ Сделано               │
│  09:30 ●  Завтрак                        │ ✓ Полить цветы 14:05  │
│        │                                 │                       │
│  14:05 ✓  Полить цветы                   │ Отметка добавляет     │
│        │  из плана                       │ запись в дневник.     │
└──────────────────────────────────────────┴───────────────────────┘
```
- Левая колонка — день: заголовок (дата крупно, относительный день и день недели вторым уровнем, без обрезки),
  карточка ввода (единственная «карточка» в окне — это поле ввода, а не украшение), затем лента.
- Лента — непрерывная вертикальная ось: время справа-выровнено в узкой колонке, на оси точка; если запись
  пришла из плана — маленькая галочка. Никаких карточек на запись, разделителей-линеек между записями нет.
- Справа — панель «План на день» (≈270pt, фон pane, скрывается кнопкой в тулбаре, ⌥⌘P).
  Сначала открытые пункты, затем «Сделано» с временем записи.
- Выравнивание везде по левому краю; время — по правому краю своей колонки, чтобы цифры стояли столбиком.

## Принципы
1. Одна смелая деталь — ось времени. Всё остальное тихое и системное.
2. Ввод всегда первым и в фокусе; фокус виден (контур карточки становится акцентным).
3. План и факт разделены пространственно (справа — намерения, слева — что было). Связь видна одной галочкой.
4. Слова — действия: «Записать», «Добавить в план», «Отметить выполненным», «Вернуть в план».
5. «Итог дня» — одноразовый спокойный пересказ прожитого, а не метрика: ничего не сохраняет и не оценивает.

## Ревизия против брифа и штампов (что изменено)
- Был порыв сделать «дашборд» с карточками плана и счётчиком «2 из 5» — убрано: бриф запрещает метрики и карточки.
- Строка-метаданные через « · » («Сегодня · Воскресенье…», «… · сохранено…») — штамп; заменено на два уровня
  заголовка и обычные предложения в строке состояния.
- Отдельные карточки на каждую запись — штамп SaaS; заменено осью времени без контейнеров.
- Тёплый кремовый фон/терракота — не наш случай; база — системные цвета + холодный чернильно-синий акцент.
- Поиск оставлен в содержимом окна (а не в тулбаре): так надёжнее работает фокус ⌘F на macOS 14.
- Иконка приложения — пропущена (необязательно по брифу), чтобы не рисковать сборкой.

## Самокритика (после сборки кода)
- Убрана одна «лишняя деталь»: подписи над каждой секцией ленты остались только как короткое указание порядка.
- Узкое окно: минимальная ширина 720pt; при скрытой панели плана лента занимает всё окно.
- Нет скриншотов: у разработчика только файловые инструменты; визуальная проверка — на стороне ревьюера.

## Правила связи «план ↔ запись»
См. README, раздел «План на день». Кратко: отметка создаёт ровно одну запись (атомарно вместе с планом);
повторная отметка невозможна; «Вернуть в план» убирает запись только если её не меняли (с подтверждением),
иначе запись остаётся; удаление плана запись сохраняет; удаление записи оставляет план выполненным.
