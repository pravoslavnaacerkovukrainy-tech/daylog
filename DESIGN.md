# «Хаос Дня»: задачи и дневник

Редакция 3, 6 ноября 2026 года. Владелец согласовал единое место для планирования: раздел «Дела». Дневник показывает прожитый день и точку продолжения. Методика описана в [версии 0.7](docs/methodology/2026-11-05-self-organization-under-uncertainty.md).

## Назначение разделов

- «Дела»: входящие, проекты, задачи, день работы, срок результата, ожидание и пересмотр.
- «Дневник»: что произошло, что сделано и на чём остановилась работа.
- «Заметки»: справочные материалы, идеи и черновики без привязки к дню.
- «Спросить»: необязательный чат с xAI по заметкам.

Боковая панель «План на день» убрана из дневника. Раньше она показывала часть тех же задач по выбранной дате, но выглядела как второй независимый список. Существующие задачи, даты и связи сохраняются в общей модели.

## Переходы и создание задачи

«Новая задача» в меню «Файл», сочетание ⇧⌘N и команда в строке меню открывают существующий редактор в «Делах». Команда работает и при переходе из дневника. Уже открытый редактор задачи или проекта повторным вызовом не заменяется.

Команды показа и скрытия плана, кнопка боковой панели и отдельный редактор пункта плана удалены. «Новая запись» по ⌘N по-прежнему открывает ввод в дневнике.

## Макет дневника

```
┌ Дела | Дневник | Заметки | Спросить                         ┐
│ ‹ ›  Сегодня  [дата]                         Итог дня     │
│ Дата крупно                    Поиск по всем дням         │
│ Относительный день и день недели                          │
│ Что сделано или произошло?                               │
│ Другое время   На чём остановился   Записать               │
│                                                         │
│ 09:30 ●  Событие                                         │
│       │                                                 │
│ 14:05 ✓  Выполненная задача                              │
│       │  Точка продолжения                              │
└─────────────────────────────────────────────────────────┘
```

Лента занимает доступную ширину. Заголовок даты, ввод и поиск остаются на прежних местах. Время выровнено по правому краю своей колонки; на оси отображается точка, а у выполненной задачи галочка.

## Связь задачи и записи

Выполнение задачи в «Делах» атомарно создаёт одну запись дневника с текущим временем. Повторная отметка не создаёт вторую запись. Возврат задачи в работу удаляет связанную запись только если её не меняли; изменённая запись остаётся. Удаление задачи сохраняет запись, удаление записи сохраняет отметку выполнения задачи.

Схема хранения, идентификаторы и миграции не меняются. Поля старого плана остаются частью совместимой модели данных и экспорта.

## Проверка изменения

Существующие self-tests ядра проверяют хранение, совместимость и связь выполнения с дневником. UI проверяется сборкой и отдельным временным профилем: нет панели плана и её команды, ⇧⌘N открывает «Дела», выполнение появляется в дневнике, повторный вызов не затирает открытый редактор. Перед заменой установленного приложения сохраняется резервная копия.
