## День — без давления и лишних цифр

«Ход дня» помогает разгрузить голову: зафиксировать то, что уже произошло, наметить несколько дел и спокойно перечитать день. Здесь нет таймеров, напоминаний, streaks и оценки продуктивности.

Приложение особенно задумано как бережный помощник при СДВГ: можно коротко записать мысль, оставить пометку **«на чём остановился»** и легче вернуться к прерванному занятию.

## Возможности

| | Что внутри |
|---|---|
| **Дневник дня** | Короткие записи с отметкой времени, в том числе задним числом. Необязательный контекст «на чём остановился». |
| **План дня** | Небольшой список без сроков и приоритетов. Выполненный пункт автоматически становится записью дневника. |
| **Заметочник** | Идеи, справка и незавершённые мысли вне календаря. Закрепление, поиск, редактирование и локальный Markdown-просмотр. |
| **Оформление текста** | По желанию xAI/Grok превращает набросок в аккуратную заметку или причёсывает черновик записи. |
| **Спросить** | Вопрос к вашим заметкам: ИИ отвечает по их содержимому и показывает кликабельные источники. История беседы не сохраняется. |
| **Итог дня** | Спокойное резюме в 2–4 фразы по записи выбранного дня. Итог одноразовый и никуда не сохраняется. |
| **Поиск и экспорт** | Поиск по всем дням, экспорт данных в JSON и Markdown. |
| **Строка меню** | Приложение живёт в менюбаре: окно можно закрыть и открыть снова в любой момент. |

> [!NOTE]
> Все ИИ-функции необязательны. Без ключа xAI дневник, план, заметки, Markdown, поиск и экспорт работают полностью локально.

## Быстрый старт

Нужны macOS 14+ и Swift из Command Line Tools. Полный Xcode не требуется.

```bash
xcode-select --install  # если компилятор ещё не установлен
git clone https://github.com/pravoslavnaacerkovukrainy-tech/daylog.git
cd daylog
bash build.sh
open build/Daylog.app
```

Сборка создаст два артефакта:

- `build/Daylog.app` — готовое приложение;
- `build/Daylog-Mac.zip` — ZIP-копия для переноса.

Приложение подписывается ad hoc и собирается под архитектуру текущего Mac. Сборка **не нотаризована Apple**, поэтому на другом Mac надёжнее собрать её из исходников заново.

## Приватность

| Данные | Как хранятся и передаются |
|---|---|
| Дневник, план и заметки | Локально на вашем Mac, в `~/Library/Application Support/Daylog/entries.json`. |
| Ключ xAI | В macOS Keychain, не в файлах приложения и не в репозитории. |
| Сетевые запросы | Только после явного действия: «Причесать», «Оформить», «Итог дня» или «Спросить». |
| Аналитика и телеметрия | Отсутствуют. Фоновых подключений нет. |

Для запросов к xAI используется `store: false`. «Причесать» отправляет только текущий черновик, «Итог дня» — только записи выбранного дня. «Спросить» по вашему явному запросу отправляет в xAI все заметки.

<details>
<summary><strong>Markdown в заметках</strong></summary>

<br>

Текст хранится как обычный Markdown без конвертации и миграций. Переключатель **«Редактор / Просмотр»** показывает текущий черновик, включая несохранённые правки.

Разбор выполняется локально через Foundation и SwiftUI — без сети, WebKit, HTML и ИИ.

**Поддерживается:**

- заголовки `#` … `######` и абзацы с сохранением переносов;
- `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``;
- блоки кода в оградах ```` ``` ```` и `~~~`, включая подпись языка;
- маркированные, нумерованные и вложенные списки;
- задачи `- [ ]` / `- [x]` в режиме только для чтения;
- цитаты, горизонтальные линии и ссылки `[текст](https://…)` / `<https://…>`.

**Ограничения просмотра:**

- открываются только `http`/`https`-ссылки и только по клику;
- HTML и картинки показываются как исходный текст, ничего не загружается;
- таблицы отображаются моноширинным исходным текстом;
- setext-заголовки, сноски и HTML-блоки не поддерживаются;
- текст можно выделять и копировать в пределах одного блока.

</details>

## Сборка и тесты

`build.sh` собирает приложение во временной папке вне `~/Documents`, чтобы FileProvider не мешал подписи. Затем скрипт выполняет ad hoc подпись, строгую проверку и упаковку ZIP.

Тесты ядра не используют сеть и не обращаются к вашим данным:

```bash
bash test.sh
```

### Ключ xAI — необязательно

В приложении откройте **«День» → «Ключ xAI…»**. Ключ сохранится в Keychain. Он нужен только для ИИ-функций; остальная часть приложения работает без него.
