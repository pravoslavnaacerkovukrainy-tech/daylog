# Ход дня

**Небольшой дневник и план дня для macOS. Локальный, спокойный, без трекинга.**

</div>

---

«Ход дня» — нативное приложение для Mac, в котором удобно коротко записывать, что
уже сделано или произошло за день, и держать простой список того, что хочется сделать
сегодня. Без таймеров, серий, метрик, напоминаний и слежки за экраном — только запись
и спокойное перечитывание дня.

Приложение задумано как помощник при СДВГ: разгрузить голову, зафиксировать сделанное
и не потерять начатое.

## Что умеет

- **Дневник дня** — короткие записи с отметкой времени. Можно записать задним числом
  то, что было вне компьютера. У каждой записи есть необязательное поле
  «на чём остановился» — чтобы легко вернуться к прерванному.
- **План дня** — маленький список «что хочу сделать сегодня». Без сроков, приоритетов
  и напоминаний. Отметил пункт выполненным — он автоматически превращается в запись
  дневника.
- **Заметочник** — отдельное пространство вне времени: идеи, справка, недоделанные
  хвосты. Можно сумбурно набросать мысль, чтобы разгрузить голову, и нажать
  **«Оформить»** — ИИ (xAI/Grok, по желанию) сделает из наброска заголовок и аккуратную
  заметку. Заметки можно закреплять, искать и редактировать; переключение «День/Заметки»
  в тулбаре.
- **Спросить** — чат-вопрос-ответ по заметкам (как в Mem.ai, по желанию): задаёшь вопрос —
  ИИ отвечает, опираясь на содержимое всех заметок, и показывает заметки-источники
  (кликабельно). История беседы не сохраняется. По запросу все заметки уходят в xAI.
- **Итог дня** — одной кнопкой спокойное резюме прожитого дня (2–4 фразы) через
  xAI (Grok), по желанию. Одноразовое: в дневник не записывается и на стороне xAI
  не сохраняется. В xAI уходят только записи выбранного дня — план и другие дни нет.
- **Поиск** по всем дням.
- **Экспорт** в JSON и Markdown.
- **«Причесать»** (необязательно) — одним нажатием привести черновик записи в порядок
  через xAI (Grok). Работает только по явному действию и только если вы сами указали
  ключ (см. ниже).
- **Строка меню** — приложение живёт в менюбаре; окно можно закрыть, оно откроется снова.

## Приватность

- Весь дневник хранится **только на вашем Mac**, в одном файле
  `~/Library/Application Support/Daylog/entries.json`.
- Сеть используется **только по явному действию** («Причесать», «Итог дня», «Спросить»),
  всегда с флагом `store: false` — запрос не сохраняется на стороне xAI.
  «Причесать» отправляет только текст текущего черновика (ни дневник, ни план).
  «Итог дня» отправляет только записи выбранного дня (ни план, ни другие дни) и сам
  итог никуда не сохраняется.
- Ключ xAI хранится в **Keychain**, не в файлах приложения и не в этом репозитории.
- Нет аналитики, телеметрии и фоновых подключений.

## Сборка и запуск

Нужен только Swift из Command Line Tools — **полный Xcode не требуется**.

```bash
xcode-select --install        # если ещё нет компилятора
bash build.sh                 # сборка, ad hoc подпись, строгая проверка, упаковка
open build/Daylog.app
```

Требования: macOS 14+ (проверялось на macOS 15, Apple Silicon).

Скрипт собирает приложение во временной папке вне `~/Documents` (там FileProvider
может мешать подписи), подписывает ad hoc, строго проверяет подпись и упаковывает в ZIP.
Локальная сборка собирается под архитектуру текущего Mac и **не нотаризована** Apple —
для запуска на другом Mac надёжнее собрать из исходников заново. Обходить Gatekeeper
не нужно.

Тесты ядра (хранилище, модель, форматирование) — без сети и без доступа к вашим данным:

```bash
bash test.sh
```

### Ключ xAI (необязательно)

Нужен только если хотите пользоваться кнопкой «Причесать». В приложении: меню
**«День» → «Ключ xAI…»**. Ключ ляжет в Keychain. Без ключа приложение полностью
работает — просто без причёсывания.

## Как устроено

```
Sources/
  Core/
    DiaryCore.swift     — модель и хранилище (чистые, тестируемые, без UI)
    DraftPolish.swift   — необязательная интеграция с xAI (одна запись → одна фраза)
  App/
    DaylogApp.swift     — точка входа, окно, меню, строка меню
    AppState.swift      — состояние, связывает UI и хранилище
    Views.swift         — экраны SwiftUI
    XAIKeyStore.swift   — ключ xAI в Keychain
Tests/SelfTest/         — проверки ядра (гоняются во временном каталоге)
Resources/              — Info.plist, иконка
docs/                   — дизайн и спецификации
build.sh, test.sh       — сборка и тесты без Xcode
```

Данные хранятся в одном версионированном JSON: совместимость между версиями формата
сохраняется (старые файлы читаются, новые поля добавляются аккуратно).
