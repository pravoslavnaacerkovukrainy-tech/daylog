# Хаос Дня

**Органайзер рабочих и личных задач с элементами методики самоорганизации в условиях неопределённости, с дневником и заметками, для macOS.**

</div>

---

«Хаос Дня» — нативный органайзер для Mac: собирайте рабочие и личные задачи, выбирайте
ближайшее действие, отмечайте сделанное в дневнике и сохраняйте заметки. В приложении
нет таймеров, серий, метрик, напоминаний и слежки за экраном.

Одной из причин появления приложения была потребность разгрузить голову и не терять
начатое при СДВГ; это не единственный сценарий его использования.

## Органайзер 0.2

Раздел **Дела** открывает органайзер с переключателем **Все / Работа / Личное**.

- **Входящие** — быстрые записи без обязательной даты. При разборе выберите проект,
  состояние и ближайшее действие.
- **Проекты** — ожидаемый результат, вопросы, которые нужно выяснить, дата пересмотра
  и один следующий шаг. Создавайте задачи из проекта или связывайте с ним входящие.
- **Сегодня** — задачи с выбранным днём работы, включая оставшиеся с прошлых дней,
  и задачи с наступившим сроком. Действия без дня можно выбрать на сегодня из подсказок.
- **Состояние «Отложено»** — задача остаётся в общем списке и не появляется в «Сегодня».
- **Ожидаю** — задачи, зависящие от ответа или события. Запишите, чего ждёте,
  и когда проверить состояние.
- **Обзор** — задачи с наступившей датой пересмотра и проекты, которым нужен следующий шаг.
- **Все задачи** — общий список с поиском и возможностью показать выполненное.

Срок результата, день работы и дата пересмотра задаются независимо. При выполнении
задачи создаётся связанная запись в дневнике с фактическим временем выполнения.
Следующий шаг проекта после выполнения освобождается для нового действия.

Файлы формата v1–v3 читаются автоматически. Прежние планы отображаются как личные
задачи. Перед первым сохранением в новом формате v4 приложение создаёт точную копию
старого файла рядом с ним, с именем `entries-before-organizer-….json`.
Если другой экземпляр изменил файл, сохранение отклоняется с сообщением о конфликте.

## Что умеет

- **Дневник дня** — короткие записи с отметкой времени. Можно записать задним числом
  то, что было вне компьютера. У каждой записи есть необязательное поле
  «на чём остановился» — чтобы легко вернуться к прерванному.
- **План в режиме «Дневник»** — боковая панель задач на выбранный день; отметка выполнения
  создаёт связанную запись в дневнике. Для проектов, статусов, ожиданий, сроков и обзора
  используйте раздел **«Дела»**.
- **Заметочник** — отдельное пространство вне времени: идеи, справка, недоделанные
  хвосты. Можно сумбурно набросать мысль, чтобы разгрузить голову, и нажать
  **«Оформить»** — ИИ (xAI/Grok, по желанию) сделает из наброска заголовок и аккуратную
  заметку. «Оформить» отправляет в xAI заголовок и текст текущего наброска; заметки можно
  закреплять, искать и редактировать. Текст заметки понимает **Markdown**: переключатель
  «Редактор / Просмотр» над текстом показывает оформленный вид (см. ниже).
- **Спросить** — чат-вопрос-ответ по заметкам (как в Mem.ai, по желанию): задаёшь вопрос —
  ИИ отвечает по всем заметкам и показывает заметки-источники (кликабельно). При каждом
  вопросе в xAI отправляются заметки, вопросы и ответы текущей беседы, а также новый
  вопрос; дневник и план не отправляются. История беседы не сохраняется приложением.
- **Итог дня** — одной кнопкой спокойное резюме прожитого дня (2–4 фразы) через
  xAI (Grok), по желанию. В xAI уходят записи выбранного дня с временем и контекстом —
  план и другие дни не отправляются. Итог не записывается приложением в дневник.
- **Поиск** по всем дням.
- **Экспорт** в JSON, обычный Markdown, а также в новую папку Markdown для чтения
  в ChatGPT/Obsidian. Папочный экспорт создаёт отдельную папку внутри выбранной
  директории с `README.md`, дневными файлами и заметками, и пишет только уже
  сохранённые записи — без черновиков, без перезаписи существующих файлов.
- **«Причесать»** (необязательно) — одним нажатием привести черновик записи в порядок
  через xAI (Grok). Работает только по явному действию и только если вы сами указали
  ключ (см. ниже).
- **Строка меню** — приложение живёт в менюбаре; окно можно закрыть, оно откроется снова.
- **Режимы** — переключатель в тулбаре открывает **«Дела»**, **«Дневник»**, **«Заметки»**
  или **«Спросить»**. Кнопка **«Показать план» / «Скрыть план»** доступна в режиме
  «Дневник» и открывает или закрывает боковую панель плана.

## Markdown в заметках

Текст заметки хранится как есть — обычный Markdown-текст, без конвертации и миграций.
Над текстом есть переключатель **«Редактор / Просмотр»**: просмотр мгновенно показывает
текущий черновик (в том числе несохранённый), ничего не сохраняет и не сбрасывает правки.
Разбор полностью локальный (Foundation + SwiftUI), без сети, WebKit, HTML и ИИ.
Заголовок заметки остаётся обычным текстом.

Поддерживается:

- заголовки `#` … `######`;
- абзацы с сохранением переносов строк;
- `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``;
- блоки кода в оградах ```` ``` ```` или `~~~` — буквально, с пробелами и подписью языка,
  длинные строки прокручиваются по горизонтали;
- списки `-`/`*`/`+` и `1.`/`1)` с вложенностью по отступу (нумерация идёт подряд);
- задачи `- [ ]` / `- [x]` — показываются флажками **только для чтения**;
- цитаты `>` (в том числе вложенные), линии `---` / `***` / `___`;
- ссылки `[текст](https://…)` и `<https://…>`.

Ограничения:

- открываются только ссылки `http`/`https` и только по клику; ссылки с другими схемами
  (`file:`, `javascript:`, `data:`, `mailto:`, собственные, относительные) показываются
  обычным текстом;
- HTML не исполняется и показывается как текст; картинки `![…](…)` показываются как
  исходный текст и ничего не загружают;
- таблицы показываются как моноширинный текст исходных строк, без раскладки по ячейкам;
- нет «setext»-заголовков (`===`/`---` под строкой; `---` всегда линия), блоков кода
  отступом в 4 пробела, сносок и HTML-блоков; код внутри пункта списка завершает список;
- незакрытая ограда кода показывает весь остаток текста как код — ничего не теряется;
- выделять и копировать текст в просмотре можно в пределах одного блока;
- как и раньше, пробелы и пустые строки по краям всего текста заметки обрезаются при сохранении.

## Экспорт в папку Markdown

Сначала сохраните текущие правки. Выберите **Файл → Экспорт в папку Markdown…**
и папку назначения. Внутри появится отдельная папка `daylog-export-…`, которая
откроется в Finder:

- `README.md` — оглавление, число записей и часовой пояс;
- `Дни/ГГГГ-ММ-ДД.md` — события по времени, контекст и план дня с отметками выполнения;
- `Заметки/UUID.md` — заметки с исходным Markdown без изменений;
- `Архив.json` — все сохранённые записи, планы, заметки и связи в исходной схеме.
- `Органайзер.md` — проекты, задачи, ожидания, сроки и даты пересмотра, когда они есть.

Повторный экспорт создаёт новую папку и сохраняет предыдущие экспорты. Экспорт
выполняется локально; загрузку файлов в ChatGPT пользователь выполняет отдельно.
JSON служит полным архивом, Markdown — удобной версией для чтения.

## Приватность

- Основной файл данных приложения хранится на вашем Mac:
  `~/Library/Application Support/Daylog/entries.json`. При запросе к xAI отдельные
  данные передаются по явному действию; ниже перечислено, какие именно.
- **Экспорт в папку Markdown** создаёт новую папку внутри выбранной директории и
  сохраняет только уже зарегистрированные записи; он не пишет черновики, не смешивает
  файлы с существующими папками и не пересекается с текущими данными.
- Сеть используется **только по явному действию**: «Причесать», «Оформить», «Итог дня»
  или «Спросить». В запросах передаётся `store: false` — просьба не сохранять запрос;
  условия обработки определяет xAI.
- **«Причесать»** отправляет текст текущего черновика записи; дневник и план
  не отправляются.
- **«Оформить»** отправляет заголовок и текст текущего наброска заметки; дневник, план
  и другие заметки не отправляются.
- **«Итог дня»** отправляет записи выбранного дня с отметками времени и контекстом;
  план и записи других дней не отправляются. Ответ не сохраняется приложением.
- **«Спросить»** отправляет снимок всех заметок (заголовки и тексты), историю вопросов
  и ответов текущей беседы и новый вопрос. Дневник и план не отправляются; история
  беседы не сохраняется приложением.
- Ключ xAI хранится в **Keychain**, не в файлах приложения и не в этом репозитории.
- Нет аналитики, телеметрии и фоновых подключений.

## Сборка и запуск

Нужен только Swift из Command Line Tools — **полный Xcode не требуется**.

В CLT с SDK 27.2 может отсутствовать SwiftUIMacros. Если установлен SDK 26.5,
скрипт сборки выберет его. SDK также можно задать через `DAYLOG_SDK_PATH`.

```bash
xcode-select --install        # если ещё нет компилятора
bash build.sh                 # сборка, подпись, строгая проверка, упаковка
open "build/Хаос Дня.app"
```

Требования: macOS 14+ (проверялось на macOS 15, Apple Silicon).

Если на Mac есть локальная идентичность **Daylog Local Signing**, сборка подписывается
ей; иначе используется ad hoc. Скрипт собирает и проверяет приложение во временной папке
вне `~/Documents` (там FileProvider может повредить подпись), затем упаковывает его
в **`build/Chaos-Day-Mac.zip`** — это проверенный результат. Для постоянной установки
распакуйте ZIP вне `~/Documents`, например в `~/Applications`. Копия
`build/Хаос Дня.app` предназначена для быстрого запуска; FileProvider может повредить
её подпись. Локальная сборка под архитектуру текущего Mac **не нотаризована** Apple;
для другого Mac по-прежнему рекомендуется собрать приложение из исходников.

Тесты ядра (хранилище, модель, форматирование) — без сети и без доступа к вашим данным:

```bash
bash test.sh
```

### Ключ xAI (необязательно)

Нужен для **«Причесать»**, **«Оформить»**, **«Итог дня»** и **«Спросить»**. В приложении:
меню **«День» → «Ключ xAI…»**. Ключ хранится в Keychain. Без ключа работает всё,
кроме этих четырёх функций.

## Как устроено

```
Sources/
  Core/
    DiaryCore.swift     — модель и хранилище (чистые, тестируемые, без UI)
    Organizer.swift     — модель и операции органайзера, его экспорт
    XAIResponses.swift  — разбор ответов Responses API
    DraftPolish.swift   — необязательная интеграция с xAI (одна запись → одна фраза)
    NotePolish.swift    — оформление черновика заметки через xAI
    NotesChat.swift     — вопросы по заметкам через xAI
    DaySummary.swift    — итог выбранного дня через xAI
    NoteMarkdown.swift  — разбор Markdown заметок для просмотра (Foundation, без сети)
    MarkdownFolderExport.swift — локальный экспорт по дням и заметкам с JSON-архивом
  App/
    DaylogApp.swift     — точка входа, окно, меню, строка меню
    AppState.swift      — состояние, связывает UI и хранилище
    Views.swift         — экраны SwiftUI
    OrganizerView.swift — экран органайзера
    NoteMarkdownView.swift — просмотр Markdown заметки
    XAIKeyStore.swift   — ключ xAI в Keychain
Tests/SelfTest/         — проверки ядра (гоняются во временном каталоге)
Resources/              — Info.plist, иконка
docs/                   — дизайн и спецификации
build.sh, test.sh       — сборка и тесты без Xcode
```

Данные хранятся в одном версионированном JSON: совместимость между версиями формата
сохраняется (старые файлы читаются, новые поля добавляются аккуратно).
