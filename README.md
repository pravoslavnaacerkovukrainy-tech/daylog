«Хаос Дня» — нативный органайзер для Mac: собирайте рабочие и личные задачи, выбирайте
ближайшее действие, отмечайте сделанное в дневнике и сохраняйте заметки. В приложении
нет таймеров, серий, метрик, напоминаний и слежки за экраном.

Одной из причин появления приложения была потребность разгрузить голову и не терять
начатое при СДВГ; это не единственный сценарий его использования.

## Возможности

### Органайзер

Раздел **Дела** открывает органайзер с переключателем **Все / Работа / Личное**.

- **Входящие** — быстрые записи без обязательной даты. При разборе выберите проект,
  состояние и ближайшее действие.
- **Проекты** — ожидаемый результат, вопросы, которые нужно выяснить, дата пересмотра
  и один следующий шаг. Создавайте задачи из проекта или связывайте с ним входящие.
- **Сегодня** — задачи с выбранным днём работы, включая оставшиеся с прошлых дней,
  и задачи с наступившим сроком. Действия без дня можно выбрать на сегодня из подсказок.
- **Ожидаю** — задачи, зависящие от ответа или события. Запишите, чего ждёте,
  и когда проверить состояние.
- **Обзор** — задачи с наступившей датой пересмотра и проекты, которым нужен следующий шаг.
- **Все задачи** — общий список с поиском и возможностью показать выполненное.
- **Состояние «Отложено»** — задача остаётся в общем списке и не появляется в «Сегодня».

Срок результата, день работы и дата пересмотра задаются независимо. При выполнении
задачи создаётся связанная запись в дневнике с фактическим временем выполнения.
Следующий шаг проекта после выполнения освобождается для нового действия.

Файлы формата v1–v3 читаются автоматически. Прежние планы отображаются как личные
задачи. Перед первым сохранением в новом формате v4 приложение создаёт точную копию
старого файла рядом с ним, с именем `entries-before-organizer-….json`.
Если другой экземпляр изменил файл, сохранение отклоняется с сообщением о конфликте.

### Остальные разделы

| | Что внутри |
|---|---|
| **Дневник** | Короткие записи с отметкой времени, в том числе задним числом. Необязательный контекст «на чём остановился». |
| **План дня** | Боковая панель задач на выбранный день в режиме «Дневник». Выполненный пункт становится записью дневника. Проекты, состояния и сроки находятся в разделе «Дела». |
| **Заметки** | Идеи, справка и незавершённые мысли вне календаря. Закрепление, поиск, редактирование и локальный Markdown-просмотр. |
| **Оформить и Причесать** | По желанию xAI/Grok превращает набросок в аккуратную заметку или приводит в порядок черновик записи. |
| **Спросить** | Вопрос к вашим заметкам: ИИ отвечает по их содержимому и показывает кликабельные источники. |
| **Итог дня** | Резюме в 2–4 фразы по записям выбранного дня. Приложение его не сохраняет. |
| **Поиск и экспорт** | Поиск по всем дням, экспорт в JSON, Markdown и отдельную папку Markdown. |
| **Строка меню** | Приложение живёт в менюбаре: окно можно закрыть и открыть снова в любой момент. |

Переключатель в тулбаре открывает **Дела**, **Дневник**, **Заметки** или **Спросить**.
Кнопка **«Показать план» / «Скрыть план»** доступна в режиме «Дневник».

> [!NOTE]
> Все ИИ-функции необязательны. Без ключа xAI работает всё, кроме «Причесать», «Оформить», «Итог дня» и «Спросить».

## Быстрый старт

Нужны macOS 14+ и Swift из Command Line Tools. Полный Xcode не требуется.

```bash
xcode-select --install  # если компилятор ещё не установлен
git clone https://github.com/pravoslavnaacerkovukrainy-tech/daylog.git
cd daylog
bash build.sh            # сборка, подпись, строгая проверка, упаковка
open "build/Хаос Дня.app"
```

Проверенный результат сборки — **`build/Chaos-Day-Mac.zip`**. Для постоянной установки
распакуйте его вне `~/Documents`, например в `~/Applications`. Копия `build/Хаос Дня.app`
предназначена для быстрого запуска: если проект лежит в `~/Documents`, FileProvider может
повредить её подпись.

Сборка собирается под архитектуру текущего Mac и **не нотаризована Apple**, поэтому для
другого Mac рекомендуется собрать приложение из исходников.

### Ключ xAI — необязательно

Нужен для **«Причесать»**, **«Оформить»**, **«Итог дня»** и **«Спросить»**. В приложении:
меню **«День» → «Ключ xAI…»**. Ключ хранится в Keychain.

## Приватность

| Данные | Как хранятся и передаются |
|---|---|
| Основной файл данных | На вашем Mac: `~/Library/Application Support/Daylog/entries.json`. |
| Ключ xAI | В macOS Keychain, не в файлах приложения и не в репозитории. |
| Сетевые запросы | Только после явного действия: «Причесать», «Оформить», «Итог дня» или «Спросить». |
| Аналитика и телеметрия | Отсутствуют. Фоновых подключений нет. |

Что именно отправляется в xAI:

- **«Причесать»** — текст текущего черновика записи; дневник и план не отправляются.
- **«Оформить»** — заголовок и текст текущего наброска заметки; дневник, план
  и другие заметки не отправляются.
- **«Итог дня»** — записи выбранного дня с отметками времени и контекстом;
  план и записи других дней не отправляются. Ответ приложение не сохраняет.
- **«Спросить»** — все заметки (заголовки и тексты), вопросы и ответы текущей беседы
  и новый вопрос. Дневник и план не отправляются; историю беседы приложение не сохраняет.

В запросах передаётся `store: false` — просьба не сохранять запрос; условия обработки
определяет xAI.

<details>
<summary><strong>Markdown в заметках</strong></summary>

<br>

Текст хранится как обычный Markdown без конвертации и миграций. Переключатель **«Редактор / Просмотр»** показывает текущий черновик, включая несохранённые правки, и ничего не сохраняет.

Разбор выполняется локально через Foundation и SwiftUI — без сети, WebKit, HTML и ИИ.

**Поддерживается:**

- заголовки `#` … `######` и абзацы с сохранением переносов;
- `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``;
- блоки кода в оградах ```` ``` ```` и `~~~`, включая подпись языка;
- маркированные, нумерованные и вложенные списки;
- задачи `- [ ]` / `- [x]` в режиме только для чтения;
- цитаты, горизонтальные линии и ссылки `[текст](https://…)` / `<https://…>`.

**Ограничения просмотра:**

- открываются только `http`/`https`-ссылки и только по клику;
- HTML и картинки показываются как исходный текст, ничего не загружается;
- таблицы отображаются моноширинным исходным текстом;
- setext-заголовки, сноски и HTML-блоки не поддерживаются;
- текст можно выделять и копировать в пределах одного блока.

</details>

<details>
<summary><strong>Экспорт в папку Markdown</strong></summary>

<br>

Сначала сохраните текущие правки. Выберите **Файл → Экспорт в папку Markdown…**
и папку назначения. Внутри появится отдельная папка `daylog-export-…`, которая
откроется в Finder:

- `README.md` — оглавление, число записей и часовой пояс;
- `Дни/ГГГГ-ММ-ДД.md` — события по времени, контекст и план дня с отметками выполнения;
- `Заметки/UUID.md` — заметки с исходным Markdown без изменений;
- `Архив.json` — все сохранённые записи, планы, заметки и связи в исходной схеме;
- `Органайзер.md` — проекты, задачи, ожидания, сроки и даты пересмотра, когда они есть.

Повторный экспорт создаёт новую папку и сохраняет предыдущие. Экспорт выполняется локально
и не включает черновики.

</details>

## Сборка и тесты

`build.sh` собирает приложение во временной папке вне `~/Documents`, чтобы FileProvider не мешал подписи. Если на Mac есть локальная идентичность **Daylog Local Signing**, сборка подписывается ей, иначе ad hoc. Затем скрипт строго проверяет подпись и упаковывает ZIP.

В CLT с SDK 27.2 может отсутствовать SwiftUIMacros. Если установлен SDK 26.5,
скрипт сборки выберет его. SDK также можно задать через `DAYLOG_SDK_PATH`.

Тесты ядра не используют сеть и не обращаются к вашим данным:

```bash
bash test.sh
```
