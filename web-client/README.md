# Хаос Дня Веб (Mac)

Небольшая оболочка AppKit + WKWebView над **https://day.osintradar.net/**. Интерфейс — сам веб:
его вход, темы, экраны и общее серверное хранилище. Экраны на Swift не дублируются,
поэтому Mac и браузер всегда работают с одним сервером. Отдельной офлайн-синхронизации нет:
без сети показывается экран «Сайт недоступен» с кнопкой «Повторить».

- Bundle ID `local.chaosday.web`, отдельный от старого клиента и `plan-client`.
- Постоянный профиль WebKit этого приложения (`WKWebsiteDataStore(forIdentifier:)`): вход и
  настройки сохраняются между запусками, но не смешиваются с Safari и другими клиентами.
- Стандартный HTTPS и системная проверка TLS. Нет JS-моста, user scripts и обработчика challenge.
- Навигация: свой origin (`https://day.osintradar.net`) открывается в окне. Внешние http/https
  по клику или через `target=_blank` уходят в системный браузер. Внешние редиректы,
  iframe и прочие схемы (`file:`, `javascript:`, `mailto:` …) блокируются.
- Загрузки (экспорт): `WKDownload` с диалогом сохранения, только со своего origin, `blob:` своего
  origin и `data:`. Имя файла очищается от путей.
- Меню: ⌘R обновить, ⇧⌘H на главную, ⌘[ / ⌘] назад/вперёд, ⌘0/⌘+/⌘− масштаб, стандартная «Правка».

## Сборка и проверки

```bash
./test.sh            # самопроверка политики + смоук debug-сборки на 127.0.0.1 (NO_SMOKE=1 — без смоука)
./build.sh           # release → ../build/web/Хаос Дня Веб.app и ../build/web/Chaos-Day-Web.zip
./build.sh --debug   # debug → ../build/web/debug/ (не для раздачи)
```

Подпись ad hoc. SDK выбирается через `../plan-client/sdk.sh` (только чтение), иконка берётся из `../Resources/AppIcon.icns`.

Только в debug есть `--debug-url <loopback>` (127.0.0.1 / ::1 / localhost, непостоянный профиль),
`--smoke` и Web Inspector. В release этого кода нет: `build.sh` проверяет бинарник.

## Ограничения

- Работает только онлайн, офлайн-режим зависит от самого сайта.
- Подпись ad hoc без нотаризации: при первом запуске Gatekeeper попросит открыть через контекстное меню.
- Вход с внешним провайдером (редирект верхнего окна на другой домен) сейчас блокируется политикой.
  Если сайт начнёт его использовать, домен провайдера нужно явно добавить в `WebPolicy`.
