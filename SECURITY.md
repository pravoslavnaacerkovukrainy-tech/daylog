# Безопасность

## Поддерживаемые версии

Исправления выходят только для последней версии со [страницы выпусков](https://github.com/pravoslavnaacerkovukrainy-tech/daylog/releases/latest). Прежние сборки не обновляются.

## Как сообщить об уязвимости

Не открывайте публичный issue. Используйте приватное сообщение: вкладка **Security** -> **Report a vulnerability** в этом репозитории.

Опишите:

- версию приложения и macOS;
- что может сделать посторонний и при каких условиях;
- шаги воспроизведения на вымышленных данных (`DAYLOG_DATA_DIR` во временной папке).

Не прикладывайте свой `entries.json`, тексты дневника и заметок, ключ QwenCloud.

Ответ не гарантирован в определённый срок: это личный проект одного человека.

## Что входит в модель угроз

- Данные хранятся в `~/Library/Application Support/Daylog/` и доступны любому процессу, запущенному от вашего пользователя. Приложение не шифрует файл дневника отдельно.
- Ключ QwenCloud хранится в Keychain, не в файлах проекта и не в `entries.json`.
- В сеть данные уходят только после действия человека и только в QwenCloud. Что именно отправляется, описано в разделе [«Приватность»](README.md#приватность). Ошибка, из-за которой отправляется больше, чем там сказано, считается уязвимостью.
- Markdown в заметках разбирается локально: без WebKit, HTML и загрузки картинок. Открываются только ссылки `http` и `https` по клику.
- Готовая сборка не нотаризована Apple. Проверяйте, что архив скачан со страницы выпусков этого репозитория.

Условия обработки данных на стороне QwenCloud определяет QwenCloud.
