# Заметочник — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить в «Ход дня» третье пространство — заметочник: ручные заметки с заголовком и превращение сумбурного наброска в оформленную заметку (заголовок + текст) через xAI по кнопке.

**Architecture:** Заметки — третья сущность в том же атомарном JSON-хранилище (документ версии 3, обратно совместимый по образцу планов). ИИ-операция `NotePolish` — отдельный файл рядом с `DraftPolish`, общий разбор ответа Responses API вынесен в `XAIResponses`. UI получает режим «День/Заметки» поверх существующего окна.

**Tech Stack:** Swift 5, SwiftUI + AppKit, сборка `swiftc` без Xcode (`build.sh`), self-тесты ядра (`test.sh`). Зависимостей нет.

**Spec:** `docs/superpowers/specs/2026-11-01-notebook-design.md`

## Global Constraints

- macOS 14+, сборка под архитектуру текущего Mac, подпись ad hoc (не менять `build.sh` политику).
- Хранилище — единый файл `entries.json`, запись атомарная и через единственную точку `persist`; при `blockReason` любая мутация бросает `DiaryError.storeBlocked`.
- Формат документа: `format == "daylog"`, `currentVersion = 3`; `notes` пишется в файл только если непусто; файл без заметок остаётся v1/v2 и читается прежней сборкой.
- Весь новый код ядра (`Sources/Core/*`) должен компилироваться и в `build.sh` (маска `Sources/Core/*.swift`), и в `test.sh` (список файлов явный — дополнять).
- ИИ: модель `grok-4.7`, эндпоинт `https://api.x.ai/v1/responses`, `store: false`, ключ только из `XAIKeyStore` (Keychain). В запрос уходит только текст наброска.
- Язык интерфейса и текстов — русский; тип ошибок для xAI — существующий `DraftPolishError`.
- Даты нормализуются `diaryNormalized` (до секунды).

## Review Focus

- **Мутация на заблокированном хранилище** (`blockReason != nil`): `addNote`/`updateNote`/`deleteNote`/`setPinned` должны бросать `storeBlocked` и не перезаписывать файл. → тест в Task 2.
- **Ответ ИИ не чистый JSON** (проза вокруг, ``` -ограда, вложенные кавычки): `NotePolish.parse` обязан дать годную заметку через фолбэк, а не пустоту/исключение. → тест в Task 4.
- **Файл v3 в сборке, знающей только ≤v2**: должен быть аккуратный `unsupportedFormat("версия 3…")`, не «битый файл» и не потеря данных. → тест границы версий в Task 1.
- **Набросок длиннее лимита (6000)**: `NotePolish.requestBody` бросает `tooLong`; заметка всё равно сохраняема вручную (путь UI). → тест `tooLong` в Task 4.
- **Многострочное тело заметки в Markdown-экспорте**: переносы строк не ломают список (отступ как у записей). → тест в Task 5.

### Task 4: ИИ-операция `NotePolish`

**Files:**
- Create: `Sources/Core/NotePolish.swift`
- Modify: `test.sh` (добавить `Sources/Core/NotePolish.swift`)
- Test: `Tests/SelfTest/main.swift`

**Interfaces:**
- Consumes: `XAIResponses.extractText`/`stripCodeFence` (Task 3), `DraftPolishError`.
- Produces:
  - `enum NotePolish { static let model: String; static let endpoint: URL; static let maxCharacters = 6000; static let systemPrompt: String; static func requestBody(draft: String) throws -> Data; static func request(draft: String, apiKey: String) throws -> URLRequest; static func parse(_ data: Data) throws -> (title: String, body: String) }`
  - `struct NotePolishClient { func polish(draft: String, apiKey: String) async throws -> (title: String, body: String) }`
- `parse`: `extractText` → `stripCodeFence` → JSON `{title, body}`. Фолбэк при неудаче JSON: `body` = весь очищенный текст; `title` = первая непустая строка, обрезанная до 60 знаков (пустая → "").

    expectError("длинный") { _ = try NotePolish.requestBody(draft: String(repeating: "а", count: 6001)) }
}
test("NotePolish: чистый JSON, JSON в ограде, мусор → фолбэк") {
    let clean = #"{"output":[{"content":"{\"title\":\"Звонок\",\"body\":\"Позвонить технику про СЗІ\"}"}]}"#.data(using: .utf8)!
    let r1 = try NotePolish.parse(clean)
    check(r1.title == "Звонок" && r1.body.contains("технику"), "чистый JSON: \(r1)")
    let fenced = #"{"output_text":"```json\n{\"title\":\"Т\",\"body\":\"Тело\"}\n```"}"#.data(using: .utf8)!
    check(try NotePolish.parse(fenced).title == "Т", "JSON в ограде")
    let garbage = #"{"output_text":"Первая строка\nвторая строка"}"#.data(using: .utf8)!
    let r3 = try NotePolish.parse(garbage)
    check(r3.title == "Первая строка" && r3.body.contains("вторая"), "фолбэк: title из первой строки, \(r3)")
}
